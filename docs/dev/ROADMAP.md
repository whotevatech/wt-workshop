# WT Workshop roadmap

Shipped in 0.6: explicit station previews, detailed level-up rewards, persistent action milestones and an optional 13-step BeeBlock quest chapter.
Shipped in 0.5: expansion braces, Siphoning, seven additive modifier appearances, native recipe lookup and pack configuration.

Future candidates:
- A documented addon API for BeeBlock wax/honey and other pack-specific modifiers.
- An in-game reference book beyond the optional quest tutorial.
- More material traits and modifier artwork.
- Viewer recipe transfer.
- Continued BeeBlock and multiplayer balance testing.

Original mechanics, recipes, names and artwork can evolve through playtesting.
